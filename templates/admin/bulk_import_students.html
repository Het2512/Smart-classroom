Required File Format

Your file must have a header row with the following column names (case-insensitive):

Column Required? Description Example
username / email Required Student's username or email address (used to log in) harsh (or harsh@example.com)
password Required Plain text password (will be hashed automatically) student123
name Optional Student's full name (defaults to username) Harsh Darji
semester Optional Student's semester Sem 3
batch Optional Lab batch A

Example Excel layout:

name username password semester batch
Harsh Darji harsh pass1234 Sem 3 A
Priya Shah priya priya2024 Sem 3 B
Tip: If you include a semester column and a matching classroom exists, students will be automatically linked to that classroom.

📥 Bulk Import Teachers & Subjects

Upload an Excel or CSV file to create teacher accounts and automatically assign subjects to them.

Upload Teacher List

Accepted formats: .xlsx, .xls, .csv

Required File Format

Your file must have a header row with the following column names (case-insensitive):

Column Required? Description Example
username / email Required Teacher's username or email address (used to log in) shah_prof (or shah@example.com)
password Required Plain text password (will be hashed automatically) teacher123
name Optional Teacher's full name (defaults to username) Prof. Shah
subject_name Optional Name of the subject they teach Java Programming
subject_code Optional Unique code for the subject JV-302
subject_semester Optional Semester for this subject (e.g. Sem 3) Sem 3

Example Excel layout:

name username password subject_name subject_code subject_semester
Prof. Shah shah_prof shahpwd12 Java Programming JV-302 Sem 3
Dr. Mehta mehta_dr mehtapass Web Development WD-101 Sem 1
Tip: If a teacher account already exists, the system will keep their existing account details but **still successfully create and assign their new subject**!
